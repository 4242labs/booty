## Why not the 42labs AGPL default

Most 42labs repos are dual-licensed AGPL-3.0 plus a commercial option, because most of
them are software you run. `booty` is not software; it is a published mirror of design
artifacts whose entire purpose is to be embedded in someone else's project — loaded from
a CDN, dropped into an editor config, pasted into a settings box. A copyleft licence
would make every use the README recommends a violation of the licence attached to it.

The terms have to match what the thing is. Here it is assets, so CC BY 4.0.

`LICENSE` holds the verbatim CC BY 4.0 legal code and nothing else, so GitHub — and any
tool that identifies a licence by matching its text — identifies this repo correctly.
The dual-licensing terms that cover the rest of the fleet do not apply to this repo.
