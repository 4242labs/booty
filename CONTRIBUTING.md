# Contributing to booty

> [!IMPORTANT]
> **Nothing lands here directly.** `booty` is a published mirror: `tokens/` is regenerated
> daily from the 42labs Design System, and a pull request against it would be overwritten by
> the next sync — silently, and within a day. That is about how this repo is wired, not about
> your patch.

## What is still open

- **Issues.** A wrong token value, a broken CDN path, a theme that renders badly in a real
  editor — [open one](https://github.com/4242labs/booty/issues/new). Those are fixed upstream
  and arrive here on the next sync.
- **Questions.** <ahoy@42labs.io>. A conversation does not need a ticket.
- **Forks.** CC BY 4.0 grants you the artifacts outright. If you need the tokens to go
  somewhere they are not going, that is the real answer rather than a brush-off.

The upstream Design System repo is private, so there is no upstream issue tracker to send you
to. This one is the front door.

## What is not

Pull requests — token edits, theme tweaks, formatting. `tokens/` is generated; `themes/` is
authored upstream and mirrored. Send it as an issue and it gets fixed at the source.

## Maintenance

**Passively maintained.** The sync runs on a schedule and the repo is watched, not staffed.
Expect a reply in weeks rather than days.
